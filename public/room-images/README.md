# Room Images Folder (`public/room-images/`)

Place all your stay room photos and 360° panoramic images in this folder!

## File Naming Convention & Examples:
- **Standard Room Photos**:
  - `/room-images/room1.jpg`
  - `/room-images/room2.jpg`
  - `/room-images/living-room.jpg`
  - `/room-images/bedroom.jpg`

- **360° Panoramic Images**:
  - `/room-images/living-room-360.jpg`
  - `/room-images/bedroom-360.jpg`
  - `/room-images/terrace-360.jpg`

## Usage in Code:
Any image saved in `public/room-images/example.jpg` can be referenced in code as:
`'/room-images/example.jpg'`
